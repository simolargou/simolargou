I'm Simo, a developer based in Leipzig with a background in mathematics and training in Data Science & AI Engineering.

I like understanding how things work, then building something useful with them. My work connects Python, machine learning and APIs with interfaces people can actually use.

## Selected work

### [PulseTracks](https://github.com/simolargou/PulseTracks)
**Music discovery through data and machine learning.**

Explore audio features, find similar tracks and experiment with clustering in a React interface. The Python backend combines feature scaling, PCA, cosine similarity and clustering algorithms.

`Python` · `FastAPI` · `scikit-learn` · `React` · `Docker`

### [Library Management](https://github.com/simolargou/library-management)
**A practical application for books, borrowers and loans.**

A Streamlit interface backed by MySQL, with separate services for book management, borrower records and loan workflows.

`Python` · `Streamlit` · `MySQL` · `SQL`
